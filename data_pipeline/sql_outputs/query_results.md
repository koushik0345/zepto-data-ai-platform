### query1 — JOIN + GROUP BY + ORDER BY + LIMIT — books per category

```sql
SELECT
    c.category_name,
    COUNT(p.product_id) AS product_count
FROM categories c
JOIN products p
    ON c.category_id = p.category_id
GROUP BY c.category_name
ORDER BY product_count DESC, c.category_name
LIMIT 10;
```

### query5 — JOIN + GROUP BY + aggregate + ORDER BY — average price and rating per category

```sql
SELECT
    c.category_name,
    ROUND(AVG(p.price_inr), 2) AS average_price_inr,
    ROUND(AVG(p.rating), 2) AS average_rating
FROM categories c
JOIN products p
    ON c.category_id = p.category_id
GROUP BY c.category_name
ORDER BY average_price_inr DESC;

```
