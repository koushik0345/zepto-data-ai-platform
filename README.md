# Zepto Data & AI Platform

An end-to-end AI/ML engineering capstone project containing three connected modules:

- `data_pipeline` — web scraping, cleaning, currency conversion, SQLite storage, and SQL/pandas analysis.
- `analytics` — Titanic dataset profiling, EDA, predictive modeling, model evaluation, tuning, and regression.
- `support_assistant` — document-grounded GenAI support assistant using embeddings, ChromaDB, LangGraph, FastAPI, and local LLM support through Ollama.
